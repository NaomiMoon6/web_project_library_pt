# 📚 Biblioteca Triple Peaks

> **Projeto 3** do Bootcamp de Desenvolvedor Web da **TripleTen**.

---

## 📌 Sobre o Projeto

O **Triple Peaks** é uma página institucional desenvolvida para simular a interface web de uma biblioteca. Este foi o segundo projeto prático do bootcamp de Desenvolvimento Web da TripleTen, projetado para consolidar os fundamentos essenciais da construção de páginas estáticas a partir de um _briefing_ e design propostos.

O foco principal desta etapa foi transformar requisitos visuais e estruturais em código limpo, semântico e organizado.

---

## 🎯 Objetivos de Aprendizado

- Estruturar páginas web utilizando **HTML5 semântico**.
- Construir layouts flexíveis com **CSS3 (Flexbox)**.
- Dominar o **posicionamento de elementos** no fluxo da página (`relative`, `absolute`, `static`).
- Adotar boas práticas de organização de arquivos e folha de estilos.

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **HTML5**:
  - Marcação semântica (`<header>`, `<main>`, `<section>`, `<footer>`, etc.) para melhor acessibilidade e SEO.
  - Formatação adequada de textos, links e inserção de imagens.

- **CSS3**:
  - **Flexbox**: Alinhamento, distribuição de espaço e ordenação de elementos na interface.
  - **Propriedades de Posicionamento**: Controle do fluxo do layout e sobreposição de elementos.
  - **Box Model**: Gerenciamento preciso de margens (`margin`), espaçamentos internos (`padding`) e bordas.
  - Normalização de estilos globais.
